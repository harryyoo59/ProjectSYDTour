# SYD 투어 지도 (시안)

모바일(390×844) 3단 탐색 시안입니다. 지도 연결은 아직 없습니다.

## 열기

폴더에서 미리보기 서버를 켠 뒤 브라우저로 엽니다.

```bash
cd syd-tour-map
python3 -m http.server 5177
```

주소: `http://127.0.0.1:5177/`

화면 크기는 핸드폰(가로 390, 세로 844)에 맞춰 보시면 됩니다.
